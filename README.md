# Smart Inventory & Warehouse Management System

A full-stack enterprise warehouse management platform built using Spring Boot, Angular, AWS, and Docker.

## Features

- JWT Authentication
- Role Based Access Control
- Product Management
- Inventory Tracking
- Warehouse Management
- Supplier Management
- Purchase Orders
- Customer Orders
- Shipment Tracking
- Invoice Generation
- AWS S3 File Storage
- Docker Deployment
- GitHub Actions CI/CD

## Technology Stack

Backend:
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate

Frontend:
- Angular

Database:
- MySQL
- AWS RDS

Cloud:
- AWS EC2
- AWS S3

DevOps:
- Docker
- GitHub Actions

Testing:
- JUnit
- Postman
